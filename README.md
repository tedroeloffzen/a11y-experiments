# A11y in the AI era — experiments

A collection of experiments for the project **"A11y in the AI era"**: exploring how AI-assisted
development (code generation, design-to-code, automated audits) affects the accessibility of
what we build — and how AI can help make things more accessible.

## Structure

```
experiments/
  <NN>-<short-name>/
    README.md      # goal, approach, findings
    ...            # code, prompts, outputs
```

Each experiment is self-contained and documents:

- **Question** — what are we trying to learn?
- **Setup** — tools, models, prompts, inputs
- **Results** — what came out, measured against WCAG 2.2 AA where relevant
- **Takeaways** — what this means for a11y in an AI-assisted workflow
